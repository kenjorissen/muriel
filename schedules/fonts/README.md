# Bundled PDF fonts

The PDF renderer bundles these SIL Open Font License 1.1 fonts so that its
Unicode coverage does not depend on operating-system fonts:

- `NotoSansSC-VF.ttf`, Noto CJK commit
  `f8d157532fbfaeda587e826d4cd5b21a49186f7c`, SHA-256
  `d68bafcb48a2707749396aa12bbbd833cb70401f3a9a689fd2902c7e0d295964`.
- `NotoNaskhArabic-Regular.ttf`, Noto Fonts commit
  `2725c70baa8b0176c7577093ba1fc6179aa79478`, SHA-256
  `2f4b88e6ee50fa82c617e2d1d4ba18281cb1c6cd71c3af3ec64970c23995db4b`.

`LICENSE-OFL.txt` contains the license text for both fonts.
